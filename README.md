# 🧺 Ayocuci - Modern Laundry Management System

Ayocuci adalah aplikasi kasir dan manajemen laundry modern yang dirancang untuk membantu operasional bisnis laundry menjadi lebih cepat, praktis, dan terorganisir. Dibangun dengan fokus pada pengalaman pengguna yang *seamless* baik di desktop maupun perangkat mobile (Android/iOS).

---

## ✨ Fitur Utama
* **🚀 Hero Section Modern**: Tampilan landig page yang bersih dengan animasi *scroll reveal*.
* **📊 Bento Grid Features**: Layout fitur utama yang interaktif dan responsif.
* **📱 Mobile Optimized**: Desain yang telah disesuaikan khusus untuk kenyamanan pengguna *smartphone*.
* **🌗 Dark Mode Support**: Transisi warna yang halus untuk kenyamanan mata di malam hari.
* **✉️ Integrated Contact Form**: Memudahkan calon mitra untuk menghubungi layanan.

## 🛠️ Tech Stack
Project ini dibangun menggunakan teknologi terkini:
* **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
* **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
* **Animation**: [Framer Motion](https://www.framer.com/motion/)
* **Icons/Assets**: Emoji & Custom SVG
